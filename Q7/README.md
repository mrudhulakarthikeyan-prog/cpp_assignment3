# Q7 – Complex Number Class from First Principles
Run main.cpp. It identifies real/imaginary components, implements the required constructors
and +, -, *, /, == and <<, computes resistor/inductor/capacitor impedances at 50 Hz,
series and parallel RLC combinations, prints rectangular form and magnitude, handles
division by zero, and shows a std::complex<double> comparison. Verify the formulas:
ZR=R+j0; ZL=jωL; ZC=-j/(ωC); series=sum; parallel=(Z1*Z2)/(Z1+Z2).
Document hand calculations, class diagram, why members/friends were selected, O(1)
operation time and two-double storage, and one limitation (floating-point tolerance/model).
