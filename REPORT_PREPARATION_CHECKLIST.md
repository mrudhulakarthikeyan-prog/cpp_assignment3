# Report checklist
- [ ] Cover page, student details, GitHub URL
- [ ] Introduction, objectives, compiler/environment
- [ ] Q1 constructor types, initializer lists, delegation, default-constructor rules,
      initialization order, object states, missing-default-constructor compiler error,
      -Wreorder, explicit test, default-argument alternative, complexity
- [ ] Q2 shallow/deep memory diagrams, Rule of Three, copy-call situations, copy counts,
      independent copies, self-assignment, ASan for both versions, timings, vector/Rule of Zero
- [ ] Q3 2D memory layout, stack/block/heap lifetime order, destructor behaviour,
      missing delete and correct cleanup ASan, memory estimates, zero-row case, prediction,
      contiguous block/vector alternative and allocation count
- [ ] Q4 Money in paise, arithmetic/comparison/stream operators, carry, negative subtraction,
      operator translation, member/friend justification, double benchmark, engineering decision
- [ ] Q5 prefix/postfix, comparisons, checked Playlist subscript, invalid indices, rollover,
      O0/O2 timings, checked-access benchmark, prediction
- [ ] Q6 Text Rule of Three, operators that cannot be overloaded, copy count, self-assignment,
      empty/long messages, ASan, std::string benchmark and complexity
- [ ] Q7 requirements, class diagram, formulas, series/parallel RLC calculations,
      hand verification, divide-by-zero, std::complex comparison and limitation
- [ ] Actual screenshots, prediction evidence, conclusion and appendices
